선행: 09
목표: 2차 본 시험을 통과한 단어의 그림 주문서와 .bat가 대표님 컴퓨터 lingbeat_gpt 폴더에 들어가, 대표님이 .bat만 누르면 그림이 온다.
읽을 곳: 2차 통과 목록 · 카드 03(같은 순서) · 진행상황_Lingbeat_packs.md '주의사항'(컴퓨터 폴더 · .bat 영어 + CRLF · 주문은 하나씩)
만들 것:
1. 통과 단어의 주문서 · corpus · .bat(영어 · CRLF)를 그때 남은 다음 주문 번호부터 하나씩 만든다.
2. 기출 확인 기록이 없는 단어가 주문에 섞이지 않았는지 제작기 검사를 돌린다.
3. 데스크톱 앱 연결로 대표님 컴퓨터 lingbeat_gpt 폴더에 직접 넣는다.
4. 주문 목록 표(주문 번호 · 단어 · 그림 장 수)를 남긴다.
완료 조건: 폴더의 .bat · 주문서 크기가 작업 공간 것과 같다 · .bat 줄 끝이 CRLF다 · 주문 단어 = 2차 통과 단어(빠짐 0 · 더함 0) · 1차 주문 번호와 겹침 0.
하지 말 것: 대표님 대신 .bat 실행 · 떨어진 단어 주문 · 조립(카드 11)
