단계: 5 · 묶음: F-3 · 크기: 보통 · 모델: Opus 5.5 · 저장소: 필요 · 병렬: 카드 13과 동시 가능
선행: 04, 05
목표: 대표님 판정(OK · 부분 수정 · 전면 수정)이 반영되어 OK 단어는 잠기고, 고친 단어는 다시 검토 페이지에 오른다.
읽을 곳: 프로젝트 문서 claude/LINGBEAT_작업과정_v3_효율점검_2026-10-21.md 3-3 · 4 · 5-1절 · 검토 페이지 판정 기록(rev) · 단어 상태 카드 o1/cards/<팩ID>.md
만들 것:
1. 판정을 읽고 나눈다 — OK는 ok_lock.json, 부분 수정은 메모 원문 그대로 고침 지시서, 전면 수정은 단어 목록으로 남겨 진행상황 '다음 할 일'에 한 줄.
2. 고침 담당(한 단어씩)을 한 메시지에 띄우고, 글자 · 숫자 · 말풍선 글만 바꾸는 고침은 빠른 길로 직접 한다.
3. 장면이 바뀐 단어만 블라인드 → 묶기 → 검토 페이지 다시 올림 + 휴대폰 알림.
4. 도구 묶음 덧붙임.
완료 조건: 판정된 단어가 모두 처리 표에 있다(OK 잠금 · 고침 끝 · 전면 수정 넘김) · ok_lock 지문이 팩 지문과 같다 · 고친 단어 앱 흐름 PASS.
하지 말 것: 시험 목록 올리기(카드 07) · 판정 안 된 단어 손대기 · OK 단어 다시 묻기 · 전면 수정 단어 다시 도안
대표님께 물을 것: 없음
